This project is a 3D enemy-shooting game developed using Python, OpenGL, and GLUT. 
The player controls a character in a bounded arena while enemies continuously move toward the player. 
Players can rotate and fire bullets to eliminate enemies and increase their score. 
The game ends when all lives are lost or too many bullets are missed. It also includes cheat mode, pause functionality, and different camera perspectives.


| Key / Control          | Action                  |
| ---------------------- | ----------------------- |
| **W**                  | Move forward            |
| **S**                  | Move backward           |
| **A**                  | Rotate left             |
| **D**                  | Rotate right            |
| **C**                  | Toggle Cheat Mode       |
| **V**                  | Cheat Camera            |
| **R**                  | Restart game            |
| **P**                  | Pause / Resume          |
| **Left Mouse Button**  | Fire bullet             |
| **Right Mouse Button** | Change camera view      |
| **Arrow Keys**         | Control external camera |
